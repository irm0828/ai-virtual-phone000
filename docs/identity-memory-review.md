# 身份与记忆修复：实施及待验证记录

本次修改以会话 identityId 为私聊/群聊 Prompt 与记忆归属，阻止旧会话被 saveChatSessions 重新归属到当前身份。切换时保留聊天室和缓存分区，使原请求回复写回原 sessionId。长期/核心记忆带姓名和身份 ID；短期同步明确双方及发言人，并加入统一时间线。多人世界使用身份 worldId 分组，兼容旧双向配对。跨身份记忆按来源分别配置短期/长期/核心 Token 预算。

验证状态：只进行了源码与修改片段核对，未运行 TypeScript、lint、构建、浏览器或真实模型测试。不得视为已经通过验收。

## 必须验证的场景

- A/B 不同世界：B 的请求不得包含 A 的对话、记忆或关系。
- A/B/C 同世界：人物互不混同；关闭连通记忆后不注入他人聊天经历。
- 各来源三类预算分别生效，0 不注入，身份标签也计入预算（估算 Token）。
- A 生成中切 B，再切 C，再切 A：流式、整段、线下、群聊均写回原会话，无丢失或重归属。
- 切换加载完成前无法进入新会话发送；快速连续切换仅最新一次加载解除遮罩。
- 已有角色/应用用户绑定不覆盖会话所属身份。
- 旧双人连接迁移、离开世界、删除身份、备份导入后隔离正确。

## 尚未完整实现或审计的范围

- 同世界关系认知目前注入身份设定及显式人物关系；尚未建立从聊天中自动提取角色与各人物关系的独立认知表，不能保证关闭连通记忆时自动知道 A 是女朋友。
- 全产品跨应用投影尚未完成 identityId/worldId 数据隔离审计。短期读取在请求身份非当前身份时禁止读取当前投影，保留显式传入的原会话历史。
- 工具动作、钱包/购物、快捷指令接管及云端推送的副作用归属仍需逐条验证；本次不能保证所有异步副作用都已覆盖。
